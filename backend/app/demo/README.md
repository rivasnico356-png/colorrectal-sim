# Imágenes del caso de demostración

Imágenes de endoscopia del conjunto de datos público **HyperKvasir** (Borgli et al., 2020), licencia **CC BY 4.0**, el único dataset del proyecto. Las aportó Valentina Ramírez Solano desde el repositorio de HyperKvasir en OSF (PR #24).

| Archivo | Contenido | Etapa del caso de demostración |
|---|---|---|
| `preparacion-intestinal.jpg` | Preparación intestinal (escala de Boston, BBPS) | 2 |
| `reseccion.jpg` | Zona de resección teñida | 2 |

`app/preparar.py` las guarda en la base como recursos de la etapa 2, con el dataset y la licencia (RF-002 2.2), una sola vez.
