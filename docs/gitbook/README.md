# Colorrectal-Sim

Plataforma web educativa de simulación sobre la **detección e interpretación del cáncer colorrectal mediante imágenes médicas multimodales**, con un agente tutor de inteligencia artificial que acompaña paso a paso a la persona usuaria.

Proyecto ONCO-AI\_USC 2026 B, Línea 2 ONCO-SIM, desarrollado por el equipo **Medical programmers** en el curso Gestión de Proyectos TI 2026-B de la Universidad Santiago de Cali. Dueño del proyecto: Jair Enrique Sanclemente Castro.

{% hint style="warning" %}
Colorrectal-Sim es una herramienta educativa. Todo resultado generado por la IA es un **resultado experimental de apoyo a la detección e interpretación; no reemplaza la valoración de su médico**.
{% endhint %}

## En pocas palabras

| | |
|---|---|
| **Para quién** | Personas con cáncer colorrectal y sus familias (Usuario), profesionales de la salud y administradores |
| **Qué hace** | Casos de simulación por etapas con imágenes de colonoscopia de datasets públicos, tutor de IA, retroalimentación, progreso y estudios propios |
| **Cómo está hecho** | React + TypeScript, FastAPI (Python 3.12), PostgreSQL 16, Docker, GitHub Actions |
